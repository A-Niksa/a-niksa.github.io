VESPER · PERSONAL ASSISTANT

Vesper

A private morning briefing: today’s calendar, tasks, notes, and Gmail updates, delivered to Telegram.

One morning briefing, in Telegram

Vesper is a personal briefing assistant built and operated by Arsha Niksa. It brings today’s calendar, open-task counts, selected notes, and relevant Gmail updates into a private Telegram chat at 7:00 AM Asia/Tehran. A refresh command requests an updated briefing.

This website explains the project and its data practices. Vesper is currently a private, single-user setup; there is no public registration or mailbox connection on this website.

What Vesper reads

  • Gmail: read-only message headers, snippets, labels, and dates from explicitly authorized accounts, used for recent unread-mail summaries and daily-report alerts.
  • Apple Calendar and Reminders: event titles and times, plus the number of open tasks in each selected list.
  • Apple Notes: extracted items from one selected Backburner note, with tentative ideas marked as suggestions.

The briefing service runs on a private server. An authorized Mac publishes selected Apple snapshots while awake; each Apple section shows when it was last synced. Gmail is fetched directly by the server.

Read-only, with a clear purpose

The Gmail connection requests https://www.googleapis.com/auth/gmail.readonly. Vesper does not send, delete, archive, or modify email, and its current Gmail requests do not download full message bodies or attachments.

Selected briefing content is sent through Telegram to the owner’s paired private chat. Vesper does not use Gmail data for advertising, sale, or AI model training, and its briefing pipeline does not send mailbox content to an external language model.

Read the privacy policy for access, storage, retention, sharing, and deletion details, or the terms of use for the project’s operating limits.
